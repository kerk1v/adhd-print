Troubleshooting Guide

  • Chrome/Edge 89+: Full WebUSB and WebSerial support
  • Opera 75+: WebSerial support only (no WebUSB)
  • Firefox/Safari: Not supported - use server printing instead

Solution: Use Google Chrome or Microsoft Edge for best compatibility.

  1. Ensure printer is connected via USB or Serial cable
  2. Check that printer is powered on
  3. Verify printer drivers are installed (for Serial connections)
  4. Try refreshing the page and discovering again
  5. For USB printers: Make sure no other software is using the printer

  • Blurry text: Try "High Quality" mode or check paper width setting
  • Partial printing: Ensure sufficient paper loaded
  • No graphics: Server may be unavailable - will fallback to server printing
  • Wrong paper size: Adjust paper width setting to match your printer

When you first try to connect to a printer, your browser will ask for permission:

  1. Click "Allow" when prompted for device access
  2. Select your printer from the device list
  3. If denied by accident, you may need to reset site permissions in browser settings

Chrome: Settings → Privacy and Security → Site Settings → Additional Permissions
